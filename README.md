# Algoryx SaaS Admin Dashboard

A modern, responsive, production-quality SaaS Admin Dashboard built with **Next.js / React**, **TypeScript**, and **Tailwind CSS**. Designed following the visual design system of **[Algoryx Technologies](https://www.algoryx.in/)**.

---

## Features

- **Algoryx Design System:** Tailored dual-theme color palette supporting dynamic Dark and Light modes.
- **Responsive Architecture:** Fully collapsible mobile navigation drawer with a multi-device desktop sidebar.
- **Interactive Search Engine:** Real-time search popover in the top navbar filtering live Algoryx products.
- **Interactive Notifications Center:** Animated notification drawer supporting unread badges, mark-as-read, clear-all, and smooth right-slide deletion 


## Tech-Stack and Dependencies
- **Framework:** Next.JS
- **Styling:** Tailwind CSS
- **Icons:** lucide-react
- **Animations:** Framer Motion

## Learning Outcomes
- Scalable Frontend Architecture using Functional components and Custom React Hooks
- Handling Layout Challenges with tables, dynamic viewports and flex layouts
- State Management across modular layout wrappers and UI popovers

To build
**working directory**:/dashboard
**command**: docker build -t dashboard .

To Run:
**command**: docker run -p 3000:3000 dashboard
